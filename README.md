# Refactoring with LLMs: Bridging Human Expertise and Machine Understanding

This is a benchmark for different types of recatorings collected from Martin Fowler Catalog. We leverage different LLMs to conduct each refactoring by using different types of prompts.

---

## 🤖 Refactoring Generator Module (LLM-Based)

This module is responsible for generating refactoring solutions using multiple LLMs.  

For more details, please refer to the module’s README:  
👉 [Refactoring Generator README](https://github.com/arghavanMor/Refactoring_LLM_Benchmark/blob/master/src/Refactoring_Generator/README.md)

---

## 🔧 Refactoring Integrator Module

This module automates the process of applying code refactorings generated by Large Language Models (LLMs) and evaluating their outcomes. It integrates data preparation, project setup, refactoring application, and result storage into a unified workflow.

For detailed information about this module, please refer to its README:  
👉  [Refactoring Integrator README](https://github.com/arghavanMor/Refactoring_LLM_Benchmark/blob/master/src/Refactoring_Integrator/README.md)
